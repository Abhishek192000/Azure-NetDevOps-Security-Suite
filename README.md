## 🛠️ Deep-Dive Project Breakdowns

*   **Project 1 (`📁 01_Enterprise_Secure_Landing_Zone`)**: Layer-3 cloud networking architecture, Azure Firewall Premium routing perimeters, custom User Defined Routes, and symmetric VNet Peering transit paths.
*   **Project 2 (`📁 02_Automated_SecOps_Pipelines`)**: CI workflows via GitHub Actions cloud runners, canonical layout conformance testing, and dry-run infrastructure validations.
*   **Project 3 (`📁 03_PaloAlto_NVA_Cloud_Perimeter`)**: Network Virtual Appliance core structures, multi-interface routing isolation, and commercial vendor Marketplace billing plan authorizations.
*   **Project 4 (`📁 04_AZ104_PaaS_Storage_Isolation`)**: PaaS data-plane network perimeter lockdown, revoking public network visibility, allocating internal Private Endpoints, and mapping internal routing zones.
*   **Project 5 (`📁 05_AZ104_HighAvailability_VMSS`)**: Horizontal compute scaling via Uniform Orchestration fleets, Layer 4 Azure Load Balancer backend distributions, and metric aggregate monitoring policies.
